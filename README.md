# MCRAW Studio Native - Direkt MCRAW utan DNG

Fixar Rice Type 7 (din 4096x1480 4.7MB/frame 703MB fil)

## Bygg

1. Skapa repo på GitHub, ladda upp allt
2. Actions -> Build Native APK -> Run workflow
3. Ladda ner mcraw-native-rice-apk
4. Installera på Tab S8 Ultra
5. Lägg din .mcraw i /Download

Appen använder motioncam-decoder C++ direkt = klarar Rice Type 7 pixel-perfekt.

Layout: Vit/svart + orange selection (Final Production)
